Obsah projektu
- index.html, about.html, products.html, gallery.html, contact.html (5 HTML stránek)
- style.css   – veškeré styly včetně verze pro tisk (@media print)
- favicon.svg – ikona stránky
- images/     – fotografie produktů (JPG) a hero fotografie doutníků (JPG)

Spuštění lokálně
Otevřete index.html v prohlížeči. Web nevyžaduje JavaScript ani server.

Publikování na GitHub Pages (zdarma)
1. Nahrajte celou složku na GitHub jako nový veřejný repozitář.
2. V repozitáři otevřete Settings → Pages.
3. Zvolte Deploy from a branch, větev main a složku /(root).
4. Uložte a počkejte na vygenerování veřejné adresy.

Kontrola před odevzdáním
- Ověřte všech 5 HTML souborů na https://validator.w3.org/
- Zkontrolujte odkazy a zobrazení při šířce 800 px.
- Zkontrolujte náhled při vypnutém CSS a tisk.
